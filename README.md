# Sport Is Pressure

The Participation Layer of Live Sports

Author: Cristian Plop

## Abstract

Fans anticipate, predict, and react throughout a live match. This paper proposes a participation layer for live sports: structuring those instincts into real-time interaction and tracking prediction accuracy over time. It explores how live match data and AI interpretation can support products built around fan participation.
